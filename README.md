\# Banco Digital



Projeto de estudo em Java: um banco digital simples que roda no terminal. Feito para praticar orientação a objetos e lógica de programação.



\## O que faz



\- Depositar dinheiro

\- Sacar dinheiro

\- Consultar o saldo

\- Recusar operações inválidas (valor negativo, zero ou saque maior que o saldo)

\- Continuar funcionando se o usuário digitar letras no lugar de números



\## Como rodar



1\. Tenha o Java instalado (JDK 17 ou superior)

2\. Abra o projeto em uma IDE, como o IntelliJ

3\. Execute a classe `Main`

4\. Escolha as opções do menu digitando o número e apertando Enter



Observação: use vírgula para valores decimais (exemplo: 50,5).



\## Estrutura



\- `Conta.java`: guarda os dados da conta (titular, número e saldo) e as regras de depósito e saque

\- `Main.java`: o menu interativo e a leitura do que o usuário digita



\## Conceitos praticados



Classes e objetos, encapsulamento (atributos `private`), métodos, condicionais, laços de repetição e validação de entrada.
